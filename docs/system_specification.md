# Link! Like! Battle! システム・デザイン仕様書

本ドキュメントは、「Link! Like! Battle!」の核となるデザイン、UI、およびシステムロジックを定義したものです。今後の開発において、本仕様書に定義されたスタイルや挙動は、明示的な指示がない限り維持されるものとします。

---

## 1. デザイン・アイデンティティ (UI/UX)

### コンセプト
「プレミアム・デジタル・カードゲーム」。
高級感、躍動感、そして透明感を重視したモダンなデザイン。

### カラーパレット (Design Tokens)
- **Primary**: 深みのあるネイビーとブルーのグラデーション
- **Accent**: 鮮やかなシアン (#00f2ff) とマゼンタ (#ff00e5)
- **Glassmorphism**: 
  - 背景の透過率: 0.7 ~ 0.85
  - 背景ぼかし (backdrop-filter): 12px ~ 20px
  - 境界線: 1px の薄い白透過線 (rgba(255, 255, 255, 0.1))

### タイポグラフィ
- フォント: 'Inter', 'Roboto', 'Outfit' 等のモダンなサンセリフ体を使用。
- 見出し: 太字、わずかなレタースペーシング、テキストシャドウ。

### アニメーション原則
- すべてのインタラクションに微細なフィードバック（ホバー時の拡大、クリック時の沈み込み）を実装。
- カードの移動、ダメージエフェクトなどは CSS Keyframes を使用した滑らかな遷移を必須とする。

---

## 2. フロントエンド・アーキテクチャ

### 技術スタック
- **Core**: React 18 / Vite
- **Styling**: Vanilla CSS (index.css に集約)
- **Data Management**: CSVファイルを JSオブジェクトに変換して使用。

### コンポーネント構造
1. **TitleScreen**: ゲーム開始前のメインエントランス。
2. **DeckBuilder**: 20枚のカードを選択し、デッキを構築する画面。
3. **BattleScreen**: 実際のカード対戦を行うメイン画面。

### バトルロジック (battleEngine.js)
- **効果処理**: カードの `effect` 文字列を解析し、バフ、デバフ、コスト変動、AP回復などを処理。
- **計算順序**: 
  1. 基礎値の計算
  2. バフ/デバフの適用
  3. 特殊効果（「手札にある間...」等）の適用
  4. 最終出力

---

## 3. データ定義

### カードデータ (`data.csv`)
- `id`, `name`, `type`, `cost`, `power`, `effect`, `description` を基本属性とする。
- 効果テキスト内のキーワード（「コスト-1」「AP回復」等）は、システムが自動認識して処理する。

### ターン進行 (`ターン表.csv`)
- セクションごとの経過時間、初期ボルテージ、ボルテージ係数を定義。

## 4. 開発・運用ルール

### バージョン管理
- **GitHub**: `nyanpre/link-like-battle`
- **Branch Strategy**: `main` を開発・リリースの統合ブランチとする。

### デプロイ
- **GitHub Pages**: `gh-pages` ブランチを通じて自動デプロイされる。
- ベースURL: `/link-like-battle/`

### 禁止事項
- **デザインの簡略化**: いかなる理由があっても、現在のリッチなUI（グラデーション、ぼかし、アニメーション）を削除したり、単純なベタ塗りに変更したりしないこと。
- **ハードコードの回避**: カードのパラメータやテキストは可能な限り外部データ（CSV/将来的なDB）から取得すること。
